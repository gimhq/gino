## Context

The working tree implements live-only fs_request/fs_response, host-assigned remoteOps.fs,
capabilities JSON persistence, and SessionRegistry.onDrop. Agent transport currently keeps an
unbounded live queue across reconnects and spawns each file request independently. PTY needs
ordered session commands, connection-scoped queues and explicit process cleanup.

## Proposal

- Add pty_open/input/resize/close and pty_ready/output/exit with top-level ptyId. Frames bypass
  durable inbox/outbox and preserve bytes using base64. Open timeout handles old agents.
- Add remoteOps.pty (default false), merge supplied flags, terminate sessions on disable.
- Use pty-process 0.5.3 with async (latest stable verified at crates.io), safe Tokio IO and
  explicit child wait/kill. Track foreground jobs during terminal cleanup.
- Scope agent sessions and bounded output queues to one socket connection. Preserve command
  order; cap input/output chunks, sessions and consumer buffers; bound socket send waits.
- Add host.agents.openPty returning a ready session with write, resize, close, output and exited.
  Settle sessions on every SessionRegistry drop path and on malformed/slow-consumer failures.
- Inject the existing runtime WebSocket adapter into adminRouter. Add a Bearer-authenticated
  short-lived, single-use, agent-bound browser ticket endpoint and authorize the terminal upgrade
  using that ticket. Keep normal admin authorization and SDK runtime neutrality intact.
- Retain existing Hono/OpenAPI tooling and Rust toolchain; no unrelated stack migration.

## Risks

Race conditions at open/close/reconnect, output preceding readiness, loss of final output,
slow consumers, leftover child jobs and browser authentication are covered by dedicated tests.
Only PTY is added; exec and a terminal UI are deferred. No database migration or protocol bump.

## Scope

Agent remote_ops/config/runner/transport; host-core protocol/config/SDK; host-hono admin bridge;
standalone host composition; related tests and existing protocol/architecture documentation.

## Alternatives

Reuse one agent connection rather than adding a second transport or inbound SSH listener.
A terminal session ends with its connection; durable attach/recovery is outside this change.
